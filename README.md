# deteksi-uang-asli-dan-palsu-computer-vision
Project ini menerapkan ekstraksi fitur Color Histogram, Local Binary Pattern (LBP), dan Canny Edge Detection, serta klasifikasi berbasis aturan menggunakan Euclidean Distance. Evaluasi dilakukan menggunakan akurasi dan confusion matrix, termasuk pengujian kombinasi fitur untuk menganalisis performa klasifikasi.
